# 📊 Superstore Sales & Profit Analysis

A Python-based **Exploratory Data Analysis (EDA)** project using the Superstore dataset to analyze **sales, profit, discounts, product categories, and numerical relationships** through data visualization and statistical analysis.

---

## 📌 Project Overview

This project performs an exploratory analysis of a Superstore sales dataset using **Python**.

The analysis focuses on:

* Understanding the structure of the dataset
* Exploring sales performance across product categories
* Analyzing profit distribution
* Studying the relationship between discount and profit
* Calculating correlations between numerical variables
* Visualizing relationships using charts and a correlation heatmap
* Identifying maximum profit values across product categories

The project is implemented in a **Jupyter Notebook** using popular Python data analysis and visualization libraries.

## 🔍 Analysis Performed

### 1. Data Loading

The dataset is loaded using Pandas:

```python
import pandas as pd

df = pd.read_csv("superstore_raw.csv")
```

The first five records are displayed to understand the dataset structure.

---

### 2. Total Sales by Category

Sales are grouped by product category and visualized using a bar chart.

```python
df.groupby("Category")["Sales"].sum().plot(kind="bar")
```

This helps analyze the total sales generated by different product categories.

---

### 3. Profit Distribution

A box plot is used to visualize the distribution of profit values.

```python
plt.boxplot(df["Profit"])
```

This provides a visual representation of profit variation and potential outliers.

---

### 4. Discount vs Profit Analysis

A scatter plot is created to examine the relationship between discount and profit.

```python
plt.scatter(df["Discount"], df["Profit"])
```

This visualization helps investigate how different discount levels relate to profit values.

---

### 5. Correlation Analysis

The correlation between numerical variables is calculated using:

```python
df.select_dtypes(include="number").corr()
```

This helps identify relationships between numerical attributes such as:

* Sales
* Quantity
* Discount
* Profit

---

### 6. Correlation Heatmap

A Seaborn heatmap is used to visualize the correlation matrix.

```python
sns.heatmap(
    df.select_dtypes(include="number").corr(),
    annot=True,
    cmap="coolwarm"
)
```

The heatmap provides a visual representation of positive and negative relationships between numerical variables.

---

### 7. Maximum Profit by Category

The maximum profit value for each product category is calculated using:

```python
df.groupby("Category")["Profit"].max()
```

This helps identify the highest recorded profit within each category.
